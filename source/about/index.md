## 写过的一些小项目

### Ngwg

[![Ngwg](//img.shields.io/badge/Ngwg-0.2.0-3273d2)](//github.com/Ngwgers/Ngwg-core)

[Ngwg](//github.com/Ngwgers/Ngwg-cli) 是一款基于 Fish 和 TypeScript 的静态博客生成器，也是 Fewu 的后继者。
Ngwg 本质上是 Fewu 的第 6 次重构。与之前5次不同的是，本次重构首次在代码中引入了 AI 生成的代码，这显著提高了
Ngwg 的开发速度。

Ngwg 将不会在 npm 上发布，而是托管于 GitHub （未来可能在其他社区设立镜像）。
只需克隆 [Ngwg](//github.com/Ngwgers/Ngwg-cli) 的入口即可。

Ngwg 仅强依赖以下软件包：
    - Fish, 用于执行主脚本
    - Bun, 用于执行业务脚本
    - Git, 用于插件管理

### Fewu

[![Fewu](//img.shields.io/badge/Fewu-3.7.85-3273d2)](//github.com/fewu-swg/fewu)

[Fewu](//github.com/fewu-swg/fewu) 是一个静态博客生成器，类似于 Hexo，但更加小巧。
Fewu 完全开源！

Fewu 可以在 npm 上下载。包名为 `fewu-cli`，可执行文件名为 `fewu`。

同时，Fewu 有一个配套主题：
* `Next`，类 Fuwari。此主题具有与最新版 Fewu 最好的兼容性。
* `NEXTario`，类 Fuwari / Firefly 。是Next主题的分支，也是本网站使用的主题。
